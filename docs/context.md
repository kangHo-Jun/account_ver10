# 개발 Context

- 기존 시스템(카드결제 30분 자동화)은 절대 중단 없이 운영

## 현재 상태 (2026-05-12)

- 기존 자동화: 정상 운영 중 (30분 주기)
- 로컬 master: `v0512_추가개발전` 롤백 상태
- origin/master: PG 코드 포함 상태
- PG 개발 브랜치: `pg_개발중`

## PG 사이클 현재 문제

- 실패 원인: `button#apply` 팝업 셀렉터 클릭 실패
- 1회 테스트 후 롤백
- 코드 위치: `pg_개발중` 브랜치
  - `modules/pg_reader.py`
  - `modules/pg_transformer.py`
  - `main.py` 2시간 PG 사이클

## 앞으로 해야할 일

## 1단계: PG 팝업 문제 해결

- `pg_개발중` 브랜치에서 작업
- Mac에서 개발 → 테스트 → GitHub 푸시
- `button#apply` 팝업 셀렉터 수정
- Windows PC 운영 시스템 건드리지 않음

## 2단계: PG 사이클 단독 테스트

- 별도 테스트 스크립트 작성
- 운영 `main.py` 건드리지 않고 단독 테스트
- 정상 확인 후 운영 코드에 통합

## 3단계: 운영 통합

- 기존 시스템 정상 확인 후
- 업무 외 시간에 통합
- 통합 후 즉시 정상 동작 확인

## 개발 규칙

- 개발 환경: Mac 또는 별도 브랜치
- 테스트: 운영과 분리된 스크립트
- 운영 반영: 검증 완료 후만
- 롤백 기준: 깃 태그 항상 유지

## 깃 브랜치 구조

- `master` (로컬): `v0512_추가개발전` 롤백 상태 = 현재 운영 코드
- `origin/master`: PG 코드 포함
- `pg_개발중`: PG 개발 진행 브랜치
